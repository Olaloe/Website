# Olaloe Website

Static website for Olaloe — built for GitHub Pages.

## How to publish on GitHub Pages (free, no domain needed)

### Step 1 — Create a GitHub account
Go to [github.com](https://github.com) and sign up if you don't have an account.

### Step 2 — Create a new repository
1. Click the **+** button (top right) → **New repository**
2. Name it exactly: `olaloe` (or any name you like)
3. Set it to **Public**
4. Click **Create repository**

### Step 3 — Upload the files
1. In your new repository, click **uploading an existing file**
2. Upload the whole `olaloe-site` folder contents:
   - `index.html`
   - the `images/` folder with all photos
3. Click **Commit changes**

### Step 4 — Enable GitHub Pages
1. Go to **Settings** → **Pages** (left sidebar)
2. Under **Source**, select **Deploy from a branch**
3. Choose branch: `main`, folder: `/ (root)`
4. Click **Save**

### Step 5 — Your site is live!
After 1–2 minutes, your site will be live at:
`https://YOUR-USERNAME.github.io/olaloe/`

---

## Updating the site later
To change text or add photos, just edit `index.html` or upload new images in the `images/` folder directly on GitHub. Changes go live automatically in a few seconds.
